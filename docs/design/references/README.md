# Reference images

権利上利用可能な参照スクリーンショットだけをここへ置く。**第三者サイトの画像はこのリポジトリへコミットしない。**
参照した事実と、そこから採り入れた属性だけを記録する。

各参照について記録すること:
- 出典URLと取得日
- 対象が homepage / app / desktop のどれか
- viewport、DPR、ブラウザ、ページ位置、表示状態
- 採用したい属性
- 模倣しない属性と理由
- 誰が画像を実際に開いて確認したか

参照先のHTMLだけを取得した場合は VISUAL UNVERIFIED。
LPのhero動画やモックが、実製品にそのまま存在するとは限らない。

### 採り入れた属性

- ファーストビューが**1本の動画ではなくDOMのレイヤー**で組まれている（背景・光沢・アプリUI・テキストが別要素）。
  → Reachmadeでは `signature-scene`（6状態の再現UI）として実装。画像素材は使わずCSSのみ。
- アプリ一覧が**同じDOMを2セット持つ無限マーキー**。
  → `sig-marquee` として実装。2セット目は `aria-hidden="true"`。
- **主操作が1つ**に絞られたファーストビュー。
  → 「プロダクトを選ぶ」1つ + 補助のテキストリンク1つ。
- FAQと、製品の入手条件に答えるセクションを持つこと。
  → `#faq` と `#access` として実装。

### 模倣しない属性と理由

- **Wall of Love（証言9件・「20,000+ voicepilled」）**：Reachmadeには検証済みの利用者証言がない。
  台帳にない実績を書かないというhonesty invariantに反する。
- **1x / 4x / 10x の生産性比較**：同条件の測定をしていない。数値の捏造になる。
- 空の写真・レンズ表現などの装飾レイヤー：`docs/DESIGN.md` の「意味のない発光を置かない」方針と衝突する。

### 未確認

- VoiceOSの実装技術（Framer Motion / GSAP / Lenis等の採用有無）は公開情報からは断定できない。
- スクロール連動の実挙動、モバイル実機での見え方、時間経過の演出は観測していない。
- 両サイトを同条件で並べた比較、利用者テストは実施していない。**優劣は測定していない。**

### 採り入れた属性

- **特大2行の主張**（参照は約96px、weight 700超、letter-spacing極小）。
  → トップのh1を `clamp(37px,4.35vw,63px)` から `clamp(38px,5.3vw,80px)` / `-.058em` / weight 650 へ。
- **見出し上の事実ピル**（参照は「New Component every week」）。
  → `.rm-hero-badge`。内容は公開情報の確認日と、実録画・検証記録の公開のみ。どちらもページ内の別箇所で既に述べている事実。
- **極小のドット区切りメタ行**（参照は `• React • TypeScript • Tailwind`）。
  → `.rm-hero-evidence`。確かめられる証拠の3種類（実録画 / 保存済み成果物 / 検証記録とBLOCKED項目）。
- **行末の丸い→アフォーダンス**（参照はカード下の丸ボタン）。
  → task pickerの各行と製品カードの主リンク。hoverで深緑に反転。
- **大きく詰めたセクション見出し**（参照は "Featured Components" 等）。
  → `.rm-band-head h2` / `.lab-collection-heading h2` / `.rm-faq-intro h2` / `.lab-work-with h2`。
- **左右がマスクで溶ける横帯**：既存の `sig-marquee` と同手法だったため、文字サイズのみ寄せた。

### 模倣しない属性と理由

- **利用者の声カード群（6件、氏名・職種つき）**：検証済みの利用者評価がない。honesty invariantに反する。
- **角丸・完全なピル・寒色グレー・黒CTA**：`tokens.md` の角丸ほぼ0・1px罫線・暖色ペーパー `#f5f4ef`・深緑 `#294536` と衝突する。新しく入れたピルはバッジの1箇所だけで（ヘッダーCTAと締めCTAは以前からピル形）、面とカードは丸めていない。配色は変更しなかった。
- **製品カードの角丸化**：`outcome-first.css` が意図的に `border-radius:0` を設定し、`lab-signature.css` が段差レイアウトを持つ。3層と承認済み方針に逆らうため見送った。
- **紫グラデーションの発光プレビュー（Fractal Glass等）**：`docs/DESIGN.md` の「意味のない発光と紫グラデーションを置かない」方針に反する。
- **巨大ゴーストワードマーク**：3配置（流し込み / ヒーロー床に絶対配置 / 積み順修正）を実装して撮影したが、参照はヒーロー下端が空いているから成立する。こちらは同じ位置に実録画パネルと橋渡し行があり、空白を作ると「主張の直後に証拠」というbriefの署名が崩れる。**不採用。**
- **Tailwind / Motion / GSAP / canvas / WebGL / 外部フォント（fontshare の Satoshi、Google Fonts の Bebas Neue）**：npm依存ゼロ、`script-src 'self'`、外部フォント禁止の不変条件に反する。すべて素のCSSに翻訳した。

### 未確認

- 参照サイトのスクロール連動挙動、hover演出、実機での見え方は観測していない（headlessの静止画とHTMLのみ）。
- 両サイトを同条件で並べた比較、利用者テストは実施していない。**優劣は測定していない。**
- 参照の正確なトークン値（色・型）は公開CSSから特定していない。採り入れたのは構成と型階層であり、数値の複製ではない。
