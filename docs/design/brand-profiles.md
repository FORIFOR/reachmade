# Shared quality, separate product identities

以下はReachmade各製品向けの提案であり、現在の実装監査結果ではない。
既存ブランドの承認済み方針がある場合はそちらを優先する。

| 製品 | 優先する体験の提案 | その製品らしい表現の案 |
|---|---|---|
| Reachmadeのサイト | 製品の目的と実際の成果がすぐ分かる | 製品ごとに異なる仕事の変化を見せる |
| Multibot | 初心者にも会話の主体と次の操作が分かる | ポップで親しみのあるボット、ユーザーが選ぶ絵文字 |
| Oathra | 誰に何を依頼し、実行前後に何が起きるか分かる | 通話依頼と確認済み結果の明確なつながり |
| AI Meeting | 会話を邪魔せず、結果に辿り着ける | 会話から決定・次の行動への整理 |
| AISecure | 安全状態・理由・対処が分かる | 遮断だけでなく安全に続ける選択肢 |
| Genie | 自分の操作を奪われず作業を任せられる | 作業の入口と必要な時だけ現れる進捗 |
| Launchloom | 初心者でも次に何をすればよいか分かる | 準備→確認→公開の短い一本道 |

全製品へ同じhero、同じダーク背景、同じカード列、同じmotionを配布しない。
共有するもの: 検証工程、証拠形式、アクセシビリティ基準、部品設計原則。
分けるもの: 情報構造、内容、色の役割、キャラクター、signature interaction。
