# 日英LP：明瞭さ・操作・表示品質の確認条件

対象はReachmadeの日本語・英語LPと、その入口から到達する実在の製品・相談ページ。
ユーザーの高いデザイン品質の要望を、下記の観察可能な条件で検証する。
世界順位や競合優位は、比較対象・同条件の観察・利用者評価がない限り断定しない。

## 主目的

現在の実装上の仮定は「企業の開発相談を主操作とし、7製品の評価へもすぐ進める」。
ユーザーには主目的を質問しており、人間がこの優先順位を承認したとは扱わない。
製品の能力・状態・証拠・画像の出所は台帳を正本とする。

| ID | 観察する結果 | 根拠となる確認 |
|---|---|---|
| L1 | 日英とも、ラボが何を作るか・相談できること・製品評価への入口が最初の画面で分かる | 390×844・1280×720・1440×1000の実画像、CTAの位置と文言 |
| L2 | 言語を切り替えても、相談→企業支援→7製品→条件比較→方針→FAQの構成が一致する | 実ページの日英切替、実在するローカライズ済みリンクと表示文言 |
| L3 | 7製品すべてが用途・状態・画像の種類・直接の利用入口を持つ | 台帳との照合、各カードの画面と遷移。Noaの非公開ソースを架空リンクで補わない |
| L4 | 映像は明示的な再生操作だけで始まり、選択変更で停止する。同時に再生する映像は1本以下 | 実映像URL・時刻進行・停止・連続選択のブラウザ検証 |
| L5 | Arrow/Home/Endで選択でき、Tabで選択中の映像の再生ボタンへ進める。フォーカスが切れない | 実キーボード操作、ARIAの関連付け、フォーカス中の画像 |
| L6 | 映像の読み込み失敗で選択・説明が失われず、再試行または製品詳細へ進める | 実媒体リクエストを中断する障害注入と、解除後の実媒体再生。架空の成功応答は作らない |
| L7 | 320/390/768/960/1024/1440/1920幅で本文・操作が隠れず横はみ出しがない | 日英の実測と画像。自動検査だけで文字の読みやすさを判定しない |
| L8 | JavaScriptなしでも全製品・説明・FAQ・直接リンク・native動画が使える | JS無効の実ブラウザ、native detailsの開閉・リンク確認 |
| L9 | reduced-motionで動きが不要になり、操作と情報が失われない | 実ブラウザの設定、スタイル値、操作、画像 |
| L10 | 小さい本文と補足に十分な文字コントラストがある | 実ブラウザの計算済み文字色・背景色から算出。画像内の文字は別評価 |
| L11 | 現行LPで使わない旧UIモジュールや、操作前の動画を読み込まない | ブラウザの実通信・受信バイトと独立したHTTPサーバー記録。転送前のイベントを実ダウンロードと混同せず、測定不能は合格にしない |
| L12 | 公開済みの製品ページ・映像・問い合わせ経路を保つ | 公開版b79ab54とのソース照合、437件を基準とする実テスト、製品媒体のhash/codec/delivery確認 |
| L13 | 既存の29枚の規定画像を、現在の実ページと指定状態から取得してレビューする | CIで生成したPNG・撮影条件・ソースSHA/指紋、独立した画像レビューとローカル証拠ゲート |
| L14 | 本番公開前に、CIと変更箇所の独立レビューで重大な未解決がない | 最新PRのchecks、現行画像のレビュー、残る手動項目の明記 |

L5のタブ操作は[WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)を参照する。
L10は[WCAG 2.2 Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)を参照し、
通常の文字4.5:1、大きい文字3:1を基準とする。これだけでWCAG全体への適合を主張しない。

実機Safari/iPhone、VoiceOver、OS文字拡大、対象利用者による評価は、自動CIや画像レビューの代替ではない。
未実施なら未確認として残す。UIの好み、機能の成否、比較上の優劣は別々に記録する。
