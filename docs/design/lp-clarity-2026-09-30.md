# 日本語LP：相談と製品評価への入口を整理

## 変更の目的

初訪問者が何を開発するラボかを理解し、企業相談か製品評価へ進めるようにする。
前の会話で提案した構成をユーザーがGitHubでの実装対象として指定したため、その案を展開した。
企業の開発相談を主操作に置くのは実装上の判断であり、利用者テストやコンバージョン改善の実測ではない。
生成り・墨色・朱色の句点、外部フォントなし、npm依存なしを維持。

## 最終構成

1. 主張と企業向け支援の説明、相談CTA、手動で選ぶ製品映像を同じ入口に配置。
2. 企業向け開発支援。
3. 台帳にある6製品の用途・成果・利用入口。映像と詳細条件はnative detailsに保持。
4. 公開サイトにある夜澄ノアの配信入口。
5. 開いて比較できる利用条件・ライセンス表。
6. 設計方針と開発者・検証記録へのリンク、FAQ、相談CTA。

台帳の証拠条件は製品映像に隣接し、共有プレイヤーでも選択に追随する。
TaskDockの未リリース設計は製品ページへ誘導する。ステージによるスクロール演出は撤去。
静止画の自動切替・ズーム・入場待ち時間はなく、動画は選択だけでは再生しない。
ネイティブの再生・一時停止・シーク・全画面操作を維持。製品詳細を閉じた場合はその動画を止める。
