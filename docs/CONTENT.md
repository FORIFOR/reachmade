# Content rules / provenance

## Sources

2026-09-15にGitHub連携で各製品の現行READMEを読み、サイトの記述を作成。詳細はcontent-sources.json。アプリの実行、性能の再測定、顧客環境での受け入れテストはこのサイト制作では行っていない。

製品パネルの画像は、各プロジェクト内で公開されている検証記録から選び、Reachmadeの静的アセットとして縮小掲載している。Reachmade側で新たに録画・再検証したものではないため、画面上でも公開記録由来であることを示す。対応表と元ファイルは`content-sources.json`の`preview` / `previewSource`に記録する。

## Must keep

- Genie: 現在のリポジトリ名はgenie。セットアップが必要なdeveloper preview。プロジェクト全体のOSSライセンスは未設定。自動で仕事を何でも完遂するとは書かない。
- AI Meeting: 確認済みのタスク変更とブラウザ内保存。録画は合成音声入力・実Gemini応答・一部スクリプト確認。登録不要のタスクと認証が必要な音声体験を分ける。
- Oathra: 会話での合意は、予約システムへの登録の証明ではない。シミュレーターと実電話を分ける。実電話は設定と費用が必要。
- AI Secure: ログスナップショットの調査用試作。常時監視・実際の遮断・漏えいの確定ではない。合成データの結果を実環境性能と呼ばない。
- Agent Team: 単一エージェントに対する品質優位は未確立。比較には失敗やprovider制約が含まれる。部分完了の記録を完走デモと言わない。
- Launchloom: ローカル・単一利用者向けalpha。生成とSNS投稿は別工程、実SNS投稿は検証未完了。集客成果を保証しない。

## Business page

企業向け支援は、この開発者に相談する仕事の提案。既に納品した顧客事例ではない。価格、期間、24時間体制、SLA、認証は作らない。費用・対象範囲・受け入れ条件は個別合意とする。

## Personal information

公開する人物の表記は確認済みのShuhei Horio / FORIFORに限定。購入画面の住所、電話番号、カード情報、個人メール、Cloudflareのアカウント情報はソース・サイトに含めない。

## Owner review before publication

- Reachmade Labの表記と、支援可能な範囲が実態に合うか。
- 既存のAI Meeting相談窓口をReachmadeの相談にも使うか。
- 各デモと検証記録へ実際にアクセスできるか。
- 所有者が受信テストを済ませたか。
- 公開ソースのライセンス方針。掲載する各製品のライセンスは変更しない。
- 将来、実画面を転載する際の権利と第三者アバター等の素材条件。
