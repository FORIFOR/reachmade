# Reachmade UIデモ v2

## 対象
日本語・英語のトップと6製品詳細ページ。静的HTMLを維持し、JavaScriptが動く場合のみ、製品ごとの18秒・5場面の説明用UIに拡張します。Reactや外部アニメーションライブラリ、外部フォントは追加しません。

Genieはワークスペースと成果物、AI Meetingは会話・確認・タスク、Oathraはサンプル会話と根拠、AI Secureはログと観測・仮説・不明点、Agent Teamは3役のボットと修正履歴、Launchloomは編集タイムラインと用途別素材を描き分けます。

## 実録画との区別
「動きで見る」は架空のサンプルデータによる説明用の再現UIです。製品本体と同じコード・UIを共有しているとは主張しません。実測速度、AIの実行結果、実通話、登録・投稿・遮断の成功を示すものではありません。「実録画を見る」で従来の実録画、根拠説明、元の録画リンクを表示します。録画は明示的な再生操作までダウンロードしません。

## 再生制御
一つのrequestAnimationFrame時計で入力・場面・再生位置を管理。手動停止、表示範囲外、非表示タブ、pagehide、動きを減らす設定を分けて扱います。手動停止はスクロールで解除しません。再開・最初から・5場面への移動・スライダー操作に対応。キーボードでの製品切替は既存タブの状態変更に同期します。

## ビルドと保守
`public/assets/animated-demos.mjs`がシナリオ・描画・再生制御、`animated-demos.css`が製品別スタイルです。`src/animated-demo-assets.mjs`がビルド時に既存のshowcase.cssへCSSを統合し、showcase.mjsの末尾へ同一オリジンの動的importを追加します。HTMLのscript・stylesheetは各1つのままです。追加モジュールが読み込めない場合は従来の実画面と録画プレイヤーが残ります。

## 検証
- 新規Nodeテスト18件を追加。シーン境界、日英の6製品、未知ID、説明上の境界、外部通信なし、CSS停止、冪等ビルドを検証します。
- 開発環境ではLinux ChromiumのDOM同等コンポーネントを用いて60項目に合格。390px/1440px、日英、6製品、キーボード切替、停止維持、CSS停止、録画切替、動的reduced-motionを含みます。これは本番サイトやSafariの検証ではありません。
- CIの既存`scripts/verify_showcase.py`を更新。実ビルドの14ページ×3幅、実録画のフレーム再生、JavaScript無効、通信失敗、reduced-motionの確認を継続し、UIデモの場面移動も検証します。CIの成功は各runの結果で確認してください。

## 公開
GitHubのマージはCloudflareへの公開と同義ではありません。既存の認証済み環境で`git pull --ff-only origin main`後に`npm run deploy`を実行します。公開後は本番の`/assets/animated-demos.mjs`に`20260919-ui-stories-2`があり、トップと6詳細ページでUIデモと実録画の切替が機能することを確認します。認証情報はソースや会話へ貼らないでください。
