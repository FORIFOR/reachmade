# 未達条件を閉じるための実測手順

対象: Genieの評価用サンプル。AI実行・問い合わせ送信は行わない。
現在のコード識別は `artifacts/ui/oss-v3/runtime.json` と
`artifacts/ui/oss-v2/final-evidence.json` を参照。

## 人間による初回操作

起動済みなら http://127.0.0.1:4192/ を開く。停止中なら `npm run dev` の
表示URLを使う。評価者への最初の課題は次だけを渡し、操作箇所を教えない。

> Genieの操作サンプルで文章を自分の内容に編集し、手元のファイルに保存してください。
> ページを開き直して、そのファイルから文章を復元してください。

OS・ブラウザ版、開始時刻、完了時刻、迷った場所、受けた助言、保存ファイル名、
復元した全文を記録する。成功条件は全文の一致、外部送信なし、復帰できたこと。
一人の結果を全ユーザーの使いやすさと一般化しない。

## 日本語IME・拡大・読み上げ

- 実OSの日本語入力を使い、「きょうのかいぎ」→「今日の会議」を未確定状態から
  変換・確定する。改行、修正、保存、再読込でも同じ文章であることを確認する。
  ペースト、AX setValue、CDP compositionイベントはこの試験の代わりにならない。
- ブラウザ自身のメニューで200%を確認し、同じ編集・保存・再読込を行う。
  Chromeで今回編集・保存まではPASS。拡張による読込はファイルアクセス権でBLOCKED。
  人が通常のファイル選択を使って確認することもできる。
- VoiceOverを使って説明、入力ラベル、エラー、操作後の移動先を確認する。
  アクセシビリティツリーを読むだけでは読み上げ試験のPASSにしない。

## 実機Safariと比較

iPhone実機のSafariで同じ課題を行い、機種・iOS版・ファイル保存/再読込結果を記録する。
MacのlocalhostはiPhoneから直接開けない。既存の承認済み配布経路がなければ、
この試験のために勝手に公開やネットワーク公開をせず、接続方法を先に合意する。
シミュレータを実機の証拠としない。

比較対象は受け入れ条件にある一般的なMarkdownエディタ（例: VS Code）。同じMac、
同じ文章で編集→プレビュー→保存→再読込を行い、両方の手数・失敗・復帰を記録する。
新規インストールや第三者送信はこの手順からは許可しない。

## 実サービス

問い合わせの認可・保存・重複防止は本リポジトリ内のUIだけで証明できない。
承認されたテスト用バックエンド、保存結果を読む方法、テストの送信範囲が必要。
ローカル応答fixtureの成功を実サービスの保存成功に置き換えない。

記録は各項目ごとに `PASS / FAIL / BLOCKED / NOT_APPLICABLE` と根拠を残す。
この手順書の存在だけではどの試験もPASSにならない。
