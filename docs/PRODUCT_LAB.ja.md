# Reachmade Product Lab

「製品を触っているように理解できる強さ」「余白と文字組みの精度」「6製品を探索するLab」を、見た目の模倣ではなく体験として実装します。

## 3つの設計判断

1. **説明から操作へ**：従来の自動UIストーリー・実録画に「操作してみる」を追加。選択→内容の確認→結果の確認を、手動で進めます。Oathraでは日時の根拠、AI Secureでは仮説と事実、AI Meetingでは確認待ちを区別する選択ができます。これはサンプル操作で、実AI・実通話・実投稿・実タスク保存ではありません。
2. **余白と階層**：トップの見出しを短くまとめ、仕事別の入口と大きな製品画面を近づけます。ページ全体の最大幅、セクション余白、見出しサイズ、操作位置を揃えます。スクロールは乗っ取らず、控えめな登場演出だけに留めます。動きを減らす設定とJavaScript無効にも対応。
3. **製品ごとの個性**：6つの用途別タブ、製品ごとに異なる静止UIイメージ、現在選択中の製品説明・コード・検証資料の同期。Agent Teamは役割別の小さなボット、Launchloomは編集素材、Oathraは発言と日時を中心に描き分けます。

## 実装

- `public/assets/lab-explorer.mjs`：共通の製品説明・アイコン、操作サンプル、選択と結果、UI同期。サンプルのMarkdown保存はブラウザ内で生成。入力・認証情報の収集や外部AI呼び出しはありません。
- `public/assets/lab-explorer.css`：新しいトップの構成と、既存の詳細ページ・UIストーリーの整合。第三者フォントや動画ライブラリは追加していません。
- `src/lab-experience.mjs`：静的ホームを生成し、トップ・6製品詳細の日英14ページに拡張フックを追加します。HTMLのscript/stylesheetは各1つのまま。既存録画・画像・問い合わせ・Worker・製品台帳は維持します。
- `scripts/verify-lab-experience.py`：実ビルドのトップ6製品×日英×3幅と、12詳細ページ、reduced-motion、JavaScript無効を検証。既存の録画再生検証に追加しています。

## 検証の扱い

新規の純粋関数・構造テスト19件と、ローカルのシェル／コンポーネント確認40項目は実行済みです。ローカルプレビューには録画ポスターのプレースホルダーを使うため、本番サイトや実録画の検証とは区別します。リポジトリ全体と実録画の結果は、該当コミットのActions結果を参照してください。CI成功前に「全テスト成功」「公開済み」とは扱いません。

## 公開と評価

マージとCloudflareへのデプロイは別工程です。認証済みの既存環境で通常の`npm run deploy`を使い、公開HTMLの`data-lab-experience="20260919-product-lab-1"`と実際の3モード切替を確認します。Safari・iPhone実機とコンバージョン比較は別途の評価です。VoiceOSより優れると実証したものではなく、指定された3要素を具体化した変更です。
