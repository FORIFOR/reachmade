# 6製品の実画面動画

実装日: 2026-09-15

## 今回の範囲

Reachmadeの日本語・英語トップと製品一覧で、Genie / AI Meeting / Oathra / AI Secure / Agent Team / Launchloomの既存公開動画をページ内で再生します。各製品の独立したLPやアプリ本体は、この変更には含めません。

動画を新たに撮影・高画質化した変更ではありません。既存の録画の短い区間を無音プレビューとして再生し、全編を大きいプレーヤーで開けるようにする変更です。動画そのものへの新しいズーム、バウンド、速度変更は加えません。

## 表示と操作

- トップ: Genieのヒーロー、AI MeetingとOathraの紹介、残る3製品のカードに動画を配置。
- 製品一覧: 全6件の静止画を動画プレーヤーへ段階的に置換。
- 一覧のプレビューは14秒前後の抜粋。全編は拡大プレーヤーから再生。
- 同時に自動再生するのは画面内の1本。画面外、非表示タブ、絞り込みで隠れた製品は停止。
- 再生、一時停止、全編の拡大、Escapeで閉じる、元のボタンへのフォーカス復帰。
- reduced-motion / 対応ブラウザのsaveDataでは自動再生せず、明示操作でのみ開始。
- メディアの読み込みは再生が必要になるまで遅延。自動再生拒否は動画の欠落と区別。
- 読み込み失敗時には元の製品サイトへのリンクを残す。
- JavaScriptが動かなければ元の静止画とリンクが残る。
- モバイルは一列。動画はobject-fit:containで画面を切り落とさない。

## 配信・プライバシー

`/media/products/<id>.mp4` をWorkerが固定の公開素材へ対応付けます。任意のURLを指定するプロキシではありません。GET/HEADと単一のbyte Range、条件付きリクエストに対応。Cookie、Authorization、Referer、X-Forwarded-Forを上流リクエストへコピーせず、上流のSet-Cookieも返しません。

ブラウザ側はReachmadeの同一オリジンから動画を取得します。第三者プレーヤー、iframe、解析SDK、永続ストレージは追加しません。CSPは `media-src 'none'` から `media-src 'self'` のみに変更し、`connect-src 'none'` と他の制限は保持します。

上流がエラー・HTML・未確認のリダイレクトを返す場合は502として扱い、再生成功を装いません。素材は各公開ホストに依存するため、公開後の定期的な到達性・再生確認は別途必要です。Cloudflare側の通常の配信トラフィックが発生します。

## テスト

`tests/films.test.mjs` に12件を追加。ローカルでは全12件PASS。対象は許可リスト、Range/HEAD/304、禁止メソッド、任意URLの拒否、個人ヘッダーの非転送、HTML/上流エラーの扱い、CSP、表示フォールバックです。

さらにローカルChromiumで、合成動画と既存DOMを模したテスト用画面を使い、次の8項目を確認しました。実サイト全体・実素材品質・Safariの検証結果ではありません。

1. 6プレーヤーの生成、画面内のみ自動再生、画面外素材の未読込。
2. 手動の一時停止・再開。
3. 拡大プレーヤー、背後の停止、Escapeとフォーカス復帰。
4. 6製品のスクロール切替と同時再生1本。
5. reduced-motionでの自動再生停止と明示再生。
6. トップの全6製品表示、390pxでの横はみ出しなし。
7. 動画欠落時のエラーと元サイトリンク。
8. 英語の操作表示。

リポジトリ全体は既存の `npm run check` / GitHub Actionsで別途確認します。Nodeテストや合成動画テストの成功を、本番の動画再生成功とは扱いません。

## 公開

Workerと静的アセットを同じバージョンでデプロイしてください。静的ファイルだけの更新では `/media/products/` が配信されません。

既存のCloudflare設定は `npm run check` → `npx wrangler@4 deploy`。GitHubへのコミットと本番公開の成功は別です。公開後、トップ・製品一覧（日本語/英語）、6動画の再生、Range応答、スマホ、停止・拡大・エラー表示を確認してください。

この作業環境からCloudflare管理画面はログアウト状態でした。認証やDNS・課金設定は変更していません。
